# 🎬 Gramini AI — Demo Video Script

**Target length:** 2 min 40 s (hard ceiling 3:00)
**Record:** 8 August, 09:15 AM — **first task of the morning, before anything else**
**Where:** a quiet room. **Not** the hall.

> **Why not the hall:** 100 people talking will ruin the microphone, and a failed
> live voice demo on camera cannot be edited out. Record clean, then the video is
> your safety net if the stage demo misbehaves.

**Actions:**

4. **Hold the shot** — show the mic reopening **by itself**

**Voice-over:**
> "एक बार दबाइए। उसके बाद कुछ नहीं दबाना। ऐप खुद सुनता रहता है।"
> *("Press once. After that, nothing. The app keeps listening by itself.")*

**Why this matters:** the single tap is a browser security rule, not our design.
Be straight about it — it is more credible than claiming zero.

## SHOT 4 ⭐ — The language switch (1:05–1:35)

**This is the best 30 seconds in the video. Hold every beat.**

**Say to the app:** `ऐप को इंग्लिश में कर दो`

**What happens:** the **entire interface** — header, cards, buttons, labels —
becomes English, and the app confirms in English.

**Then immediately say:** `मला मराठीत बोल` → whole UI becomes Marathi.

## ✅ Pre-flight checklist — do ALL of this before recording

### 30 minutes before

- [ ] **Internet ON and stable.** Hindi voice needs it — see the warning below.
- [ ] Backend running: `curl http://127.0.0.1:8000/api/health` → `"ok": true`
- [ ] Frontend running on `:5173`
- [ ] Check `gemini.last_error` is `null` in `/api/health`
- [ ] Check `models_untried` is not empty (quota headroom)
- [ ] Chrome, **not** Firefox — Web Speech API
- [ ] Close every other tab (CPU, and no notification pop-ups)
- [ ] **Do Not Disturb ON** — a Windows notification mid-take ruins it
- [ ] Charge the laptop; unplug noisy fans if possible

### ⚠️ THE ONE THAT WILL BITE YOU

**This laptop has no Hindi text-to-speech voice installed.** Only two English
voices (David, Zira).

Hindi speech works **only** through Chrome's *remote* Google voices, which need
internet. So:

1. Open Chrome DevTools console
2. Run: `speechSynthesis.getVoices().filter(v => v.lang.startsWith('hi'))`
3. **If that returns an empty array, Hindi will not speak.**

**Fixes, in order of preference:**
- Confirm internet is on and reload — Google's voices load a second or two after
  the page
- Install the Windows Hindi language pack (Settings → Time & Language → Add a
  language → हिंदी → Speech)
- **Fallback:** record the video in **English** — every feature works identically,
  and the local English voice is guaranteed

### Dry run

- [ ] Run the whole script once without recording
- [ ] Time it — if over 2:50, cut Shot 5 (weather) first
- [ ] Verify each spoken command is recognised on the first try
- [ ] Practise the pauses; do not rush Shot 4

## 🎙️ Recording tips

| Do | Don't |
|---|---|
| Record screen at 1080p, 30 fps | Zoom the browser past 125% (layout shifts) |
| Speak commands **clearly and slightly slowly** | Speak while the app is speaking |
| Wait for the app to finish before the next command | Cut the answer short in editing |
| Keep the cursor still while the app talks | Wiggle the mouse — it distracts |
| Record voice-over **separately**, after | Narrate live over the app's own voice |

**Recommended:** OBS Studio (free) or Windows `Win + G` Game Bar.

**Audio:** record the app's speech from system audio, and your narration as a
separate track. Mix so the app is audible under the narration — judges need to
hear it actually speaking.

---

## 🔁 If something fails mid-recording

| Failure | Recovery |
|---|---|
| Mic not recognised | Wait 15 s — the watchdog returns it and offers typing. Or switch to chat mode and type; still a valid demo |
| AI chat says "cannot answer general questions" | Quota. **Schemes, weather, language switching are unaffected** — skip free chat, it is not in the script anyway |
| Weather shows "Cached" | Fine — say *"and here it is serving cached data"*. It is a feature |
| Voice silent on a Hindi answer | The `🔇` strip explains it. Switch the video to English |
| App looks broken | Reload. The ErrorBoundary should have caught it; nothing is lost but the conversation |
